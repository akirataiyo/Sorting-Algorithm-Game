## 1. อีโมจิที่เอาออก

- หัวเว็บและหน้าแรก: ⚗️ (ชื่อเกม), ▶ (เริ่มเล่น), 📜 (วิธีเล่น), 📖 (สมุดตำรา)
- เมนู: 🧪 (หัวข้อเมนู), ไอคอนการ์ด 🎓 🏁 🔮 📖 (ลบทั้ง span .ico), ♻ (ปุ่มรีเซ็ต)
- หัวข้อหน้าจอ: 🎓 🏁 🔮 📖 📜 🧑‍🔬 🪄
- ฟิลด์ `icon` ใน ALGORITHMS: 🫧 🎯 🃏 ⚡ ลบทั้งฟิลด์ และลบทุกจุดที่เรียกใช้ (กฎของด่าน, บรรทัดชั้น, ตัวเลือกโหมดทาย, แท็บคู่มือ, หัวข้อคู่มือ, ตัวเลือกคู่แข่ง)
- ปุ่มเสียง: 🔊 / 🔇 เปลี่ยนเป็น "เสียง: เปิด" / "เสียง: ปิด"
- โหมดฝึก: 💡 (ปุ่มใบ้, ข้อความใบ้, tip), 🔄 ➡ ⬅ (ปุ่มตอบ), 👆 (คำสั่งคลิก), ⏱ (เปลี่ยนเป็น "เวลา"), 🎉 (จบชั้น/จบด่าน/step done), 💔 (แพ้), 🔒 🏆 (ปุ่มเลือกด่าน, ล็อกเปลี่ยนเป็นข้อความ "(ล็อก)")
- โหมดแข่ง: 🎲 🐢 🚶 🐇 (ตัวเลือก), 🏆 🪄 💥 🏳 (ข้อความผล)
- โหมดทาย: 🔮 🎉 (หน้าผล)
- คู่มือ: ▶ ⏭ ⏸ ↺ บนปุ่มสาธิต เปลี่ยนเป็น "เล่น" "ทีละขั้น" "หยุด" "เริ่มใหม่"
- ✓ / ✗ ที่ซ้ำซ้อน: "ถูกต้อง! ✓", "ตำแหน่ง … เข้าที่แล้ว ✓", "ใช่ ✓ / ไม่ใช่ ✗" ในตาราง Stable, "เสร็จ ✓"

## 3. ข้อความที่เขียนใหม่ (ตัวอย่าง)

- หน้าแรก: "ขวดยาบนชั้นวางกระจัดกระจาย! จงเรียงขวด… ด้วยวิชาเรียงลำดับ… ทั้ง 4 สำนัก" → "เรียงขวดยาตามตัวเลขพลังจากน้อยไปมาก โดยใช้ Sorting Algorithm 4 แบบ: …"
- ตั้งค่าแข่ง: "คุณและเวทมนตร์ (อัลกอริทึม) จะได้ขวดชุดเดียวกัน ใครเรียงเสร็จก่อนชนะ! แต่คุณมีจำนวนสลับจำกัด… จึงต้องคิดก่อนสลับ" → "คุณกับอัลกอริทึมได้ขวดชุดเดียวกัน ใครเรียงเสร็จก่อนชนะ คุณสลับได้ไม่เกินจำนวนสลับน้อยที่สุดที่เป็นไปได้ + 2 ครั้ง"
- ผลด่าน: "🎉 ผ่านด่าน 9!" + "ยินดีด้วย! คุณผ่านบททดสอบนักเล่นแร่แปรธาตุ…" → "ผ่านด่าน 9" + "ผ่านครบทุกด่าน ใช้ได้ทั้ง 4 อัลกอริทึมแล้ว"
- แพ้ด่าน: "💔 หัวใจหมดแล้ว — ภารกิจล้มเหลว" → "หัวใจหมด ไม่ผ่านด่าน"
- ผลแข่ง: "🏆 ชนะการแข่งขัน!" / "🪄 แพ้การแข่งขัน" → "ชนะ" / "แพ้"; "💥 ใช้งบสลับหมด…" → "สลับครบจำนวนแล้วแต่ยังเรียงไม่เสร็จ"
- โหมดทาย: "✗ ยังไม่ถูก — ผู้ชนะคือ X" → "✗ ทายผิด ตัวที่น้อยที่สุดคือ X"; "ผลจริง (…): …. ผู้ชนะ: X." → "ผลจริง (…): … น้อยที่สุดคือ X"
- คำอธิบายขั้นตอน (explainStep): ตัด " — " ออกและย่อ เช่น "…ขึ้นเป็น key ⬆ — คลิกช่อง ⤓ ที่จะวาง key…" → "…ถูกยกขึ้นเป็น key ⬆ คลิกช่อง ⤓ ในส่วนซ้ายที่เรียงแล้ว…"
- กฎอัลกอริทึม (ALGO_RULES) และคู่มือ (CODEX_INFO): ย่อประโยค ตัด "(เหมือนฟองสบู่)", "ลอย", "ดีมาก", "เร็วมาก" แต่เนื้อหาเทคนิคเหมือนเดิม
- คำอธิบายเฉลย (explainPrediction): ย่อทุกกรณี ตัวเลขจริงและ Big-O ครบเหมือนเดิม คงการแก้กรณี nearlySorted + moves ไว้ (ใช้ข้อความ movesNearly แยก)
- ข้อความท้ายผลแข่ง: ตัด "!" และย่อเป็น "…ถ้ามองเห็นวงจร คุณจะสลับน้อยกว่าอัลกอริทึมได้"
- เอากล่อง "สรุปบทเรียน: …" ในหน้าผลโหมดทายออก เพราะเฉลยทุกรอบอธิบายเรื่องเดียวกันไว้แล้ว
- เลิกใช้ " • " คั่นข้อความ (สถิติเมนู, บรรทัดชั้น, คะแนนในกฎด่าน, ลักษณะข้อมูล, ตัวเลือกโหมดทาย, ข้อความหลังตอบถูก) เปลี่ยนเป็นเว้นวรรคหรือ ", "
- ตัด "!" ออกจากทุกข้อความ UI (เริ่มแข่ง!, เริ่ม!, ชนะ!, แพ้!, ถูกต้อง!, ทายถูก!, เริ่ม X!, สถิติใหม่!) และตัด "?" ท้ายคำถามโหมดทาย/explainStep
- ปุ่มตอบ: "🔄 สลับ (S)", "➡ ไม่สลับ / ถัดไป (P)", "⬅ ไปฝั่ง < pivot (L)", "อยู่ฝั่ง ≥ pivot ➡ (R)" → "สลับ (S)", "ไม่สลับ (P)", "< pivot (L)", "≥ pivot (R)"
- `<title>`: "… — เกมเรียงลำดับ" → "…: เกมเรียงลำดับ"
- คอมเมนต์ในโค้ดที่อ้างชื่อโหมดเดิม (ฝึกวิชา, ชั้นของเวทมนตร์, ทำนาย, สมุดตำรา) เปลี่ยนให้ตรงชื่อใหม่ และย่อ "หัวใจของเกม:" ในหัวคอมเมนต์ส่วน Sorting

## 5. สิ่งที่ตั้งใจเก็บไว้

- สัญลักษณ์สถานะบนขวด ▲ ✓ ★ ⬆ ◆ ● และช่องแทรก ⤓ ใช้บอกสถานะโดยไม่พึ่งสีอย่างเดียว
- ดาว ★/☆ ในผลด่านและปุ่มเลือกด่าน, หัวใจ ♥ บอกจำนวนชีวิต (มี aria-label "หัวใจ x จาก 3")
- ✓ / ✗ นำหน้าข้อความตอบถูก/ผิด และบนตัวเลือกโหมดทายและกราฟ เพราะบอกผลโดยไม่พึ่งสี
- ลูกศร → และเครื่องหมาย < ≥ ≤ − ในคำใบ้และคำอธิบาย เป็นสัญลักษณ์คณิต/ทิศทาง ไม่ใช่การตกแต่ง
- เส้นประ "–" (en dash) ในช่วงตำแหน่ง เช่น 0–5 และ O(log n)–O(n) เป็นเครื่องหมายช่วง
- เอฟเฟกต์ที่มีหน้าที่: pulse ของคำใบ้, shake ตอนตอบผิด, pop ตอนขวดย้าย, เงาเรืองรอบขวดที่กำลังเปรียบเทียบ/pivot (ช่วยให้เห็นขวดที่ต้องดู) และพื้นหลัง gradient ของหน้า
- คอมเมนต์อธิบาย Sorting Algorithm ทั้งหมด (ส่วนที่ใช้ตรวจงาน) ยังอยู่ครบ
- ตรรกะเกม, อัลกอริทึม, การตรวจคำตอบ, คะแนน, aria-label, คีย์ลัด, localStorage key `alchemistShelf.v1` ไม่ได้เปลี่ยน

## 6. ผลการตรวจสอบ

1. แยก `<script>` ไปไฟล์ชั่วคราวใน %TEMP% แล้วรัน `node --check`: ผ่าน (exit 0) ลบไฟล์แล้ว
2. เปิดด้วย Edge headless (`--headless=new --dump-dom`): หน้าแรกแสดงผล มีขวด 8 ขวดบนชั้นตัวอย่าง ปุ่มเสียงขึ้น "เสียง: เปิด" (แปลว่า init ทำงาน) ไม่มี error ของหน้าเว็บใน console
3. Smoke test ด้วยสำเนาชั่วคราวที่ฉีดสคริปต์ทดสอบ: เปิดครบทุกหน้า (วิธีเล่น, เมนู, เลือกด่าน, ตั้งค่าแข่ง, คู่มือ, ทาย, หน้าแรก), กดสาธิตในคู่มือ, เล่นโหมดทายครบ 10 รอบจนถึงหน้าผล ("จบโหมดทาย / ระดับ: …"), เปิดด่าน 1, 3, 5, 7, 9 และเริ่มด่าน, เริ่มแข่งแล้วยอมแพ้จนถึงหน้าผล ("แพ้") ไม่มี error (`errs: []`) ลบไฟล์ชั่วคราวและโปรไฟล์ Edge ชั่วคราวแล้ว
4. ค้นหาซ้ำหลังแก้: ไม่มีอีโมจิในช่วง U+1F300–U+1FAFF เหลือ ไม่มี "•" ไม่มีคำว่า เวทมนตร์ / ฝึกวิชา / สมุดตำรา / ทำนาย ไม่มี "!" ในข้อความ UI สิ่งที่ยังเหลือ:
   - "—" สองจุด อยู่ในคอมเมนต์โค้ดเท่านั้น (คอมเมนต์ของ summarizeSteps และคอมเมนต์อธิบายกรณี nearlySorted + moves) ผู้เล่นไม่เห็น
   - สัญลักษณ์ในข้อ 5 (▲ ✓ ✗ ★ ☆ ⬆ ◆ ● ⤓ ♥) ซึ่งตั้งใจเก็บไว้
   - "?" ในกล่องยืนยันลบความคืบหน้า และหัวตาราง "Stable?" เพราะเป็นคำถามจริง

ข้อสังเกต: ด่าน 3, 5, 7 ชื่อเหมือนกัน ("ขวดสุ่ม 6 ขวด") เพราะชื่อบอกแค่ข้อมูล ส่วนชื่ออัลกอริทึมแสดงอยู่ใต้ชื่อด่านและในบรรทัดชั้นตอนเล่น
