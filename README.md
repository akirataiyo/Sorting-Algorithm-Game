# ร้านยาของนักเล่นแร่แปรธาตุ

เกมเรียงขวดยาบนชั้นตามตัวเลขพลังที่เขียนบนขวด จากน้อยไปมาก ผู้เล่นต้องเรียงตามกฎของ Sorting Algorithm ที่ด่านกำหนด หรือแข่งกับอัลกอริทึม หรือทายว่าอัลกอริทึมไหนเร็วกว่ากับข้อมูลชุดนั้น

เล่นได้ที่: https://akirataiyo.github.io/Sorting-Algorithm-Game/

ทั้งเกมอยู่ในไฟล์ `index.html` ไฟล์เดียว (HTML, CSS, JavaScript)

## อัลกอริทึมที่ใช้

- Bubble Sort (หยุดก่อนได้ถ้ารอบไหนไม่มีการสลับ)
- Selection Sort
- Insertion Sort
- Quick Sort แบบ Lomuto (ใช้ตัวสุดท้ายเป็น pivot)

โค้ดอยู่ในส่วน `// ===== SORTING ALGORITHMS =====` แต่ละฟังก์ชันเรียงข้อมูล เก็บรายการขั้นตอนที่ทำ (เปรียบเทียบ สลับ เลื่อน แทรก เลือก pivot) และนับจำนวนครั้งไว้ ทุกโหมดในเกมใช้ฟังก์ชันชุดนี้

## โหมดในเกม

ฝึกวิชา (9 ด่าน): ผู้เล่นทำหน้าที่เป็นอัลกอริทึมเอง เกมรันอัลกอริทึมจริงไว้ก่อน แล้วเทียบทุกการกดของผู้เล่นกับขั้นตอนที่ควรเป็น
- Bubble: เลือกว่าจะสลับคู่ที่ไฮไลต์หรือไม่
- Selection: กดขวดที่ค่าน้อยที่สุด ถ้ามีค่าซ้ำต้องเลือกตัวซ้ายสุด
- Insertion: เลือกช่องที่จะแทรก key
- Quick: ตอบว่าแต่ละขวดน้อยกว่า pivot หรือไม่ แล้วเลือกตำแหน่งวาง pivot

ตอบผิดจะเสียหัวใจและมีข้อความบอกว่าผิดตรงไหน ด่านที่ 9 รวมทั้ง 4 อัลกอริทึม

แข่งกับเวทมนตร์: เรียงข้อมูลชุดเดียวกับอัลกอริทึมที่ทำงานอยู่อีกฝั่ง โดยสลับได้จำนวนจำกัด จบแล้วเกมจะแสดงจำนวนสลับน้อยที่สุดที่เป็นไปได้ (คำนวณจาก cycle decomposition) เทียบกับของผู้เล่นและของแต่ละอัลกอริทึม

ทำนายเวทมนตร์ (10 รอบ): ดูลักษณะข้อมูล เช่น เกือบเรียง กลับด้าน ค่าซ้ำเยอะ แล้วทายว่าอัลกอริทึมไหนใช้ขั้นตอนน้อยที่สุด เกมรันทั้ง 4 ตัวแล้วแสดงตัวเลขจริง

สมุดตำรา: หลักการ Big-O และ stability ของแต่ละอัลกอริทึม มีตัวอย่างให้กดดูทีละขั้น

## วิธีเล่น

กด "เริ่มเล่น" แล้วเลือกโหมด

ในโหมดฝึก ตอบถูก +10 ตอบผิด −5 และเสียหัวใจ 1 ดวง (มี 3 ดวง) ใช้คำใบ้ −15 ผ่านด่านแล้วด่านถัดไปจะเปิด ความคืบหน้าเก็บไว้ในเบราว์เซอร์

คีย์ลัด: `S` สลับ, `P` ไม่สลับ, `L` น้อยกว่า pivot, `R` มากกว่าหรือเท่ากับ pivot, `H` คำใบ้, `Esc` ยกเลิกขวดที่เลือกในโหมดแข่ง

สัญลักษณ์บนขวด: ▲ กำลังเปรียบเทียบ, ✓ เรียงแล้ว, ★ pivot, ⬆ key, ● ขวดที่เลือก
