# ⚗️ ร้านยาของนักเล่นแร่แปรธาตุ (Alchemist's Potion Shelf)

เกมบนเว็บที่ใช้ Sorting Algorithm เป็นกลไกหลัก ผู้เล่นต้องเรียงขวดยาบนชั้นวางตาม "พลัง" (ตัวเลข 1–99 ที่เขียนบนขวด) จากน้อยไปมาก ทั้งเกมอยู่ในไฟล์เดียว `index.html` (HTML + CSS + JavaScript) ไม่ต้องติดตั้งหรือโหลดไฟล์อื่น เปิดในเบราว์เซอร์ได้เลย

**ลิงก์เกม:** _(ใส่ลิงก์หลังโฮสต์ เช่น https://<user>.github.io/<repo>/)_

## อัลกอริทึมที่ใช้

- Bubble Sort (มี early exit)
- Selection Sort
- Insertion Sort (stable)
- Quick Sort (Lomuto ใช้ตัวสุดท้ายเป็น pivot)

ทั้ง 4 ตัวอยู่ในส่วน `// ===== SORTING ALGORITHMS =====` ของโค้ด แต่ละฟังก์ชันจะเรียงข้อมูลจริง บันทึก "รายการขั้นตอน" (compare / swap / key / shift / insert / pivot / markSorted …) และนับจำนวนการเปรียบเทียบ การสลับ และการเขียน มีคอมเมนต์ภาษาไทยอธิบายหลักการ Big-O และ stability ไว้ ทุกโหมดในเกมใช้อัลกอริทึมชุดเดียวกันนี้

## Sorting ถูกใช้ในแต่ละโหมดอย่างไร

| โหมด | บทบาทของ Sorting |
|---|---|
| 🎓 ฝึกวิชา (9 ด่าน) | ผู้เล่นต้องลงมือทำเป็นอัลกอริทึมเองทีละขั้น เกมคำนวณขั้นตอนจริงไว้ล่วงหน้าแล้วตรวจทุกคำตอบ เช่น Bubble ให้ตัดสินว่าจะสลับหรือไม่, Selection ให้เลือกค่าน้อยสุด (ตัวแรกเมื่อมีค่าซ้ำ), Insertion ให้เลือกช่องที่จะแทรก key, Quick ให้ตัดสินว่า < pivot หรือไม่ และเลือกตำแหน่งวาง pivot ถ้าตอบผิดจะมีคำอธิบายภาษาไทยว่าผิดเพราะอะไร |
| 🏁 แข่งกับเวทมนตร์ | แข่งเรียงข้อมูลชุดเดียวกับอัลกอริทึมที่ทำงานทีละขั้นอยู่ข้าง ๆ (ไฮไลต์การเปรียบเทียบและการสลับ) ผู้เล่นมีงบจำนวนสลับจำกัด ตอนสรุปผลเกมจะคำนวณจำนวนสลับน้อยที่สุดด้วยการแยกวงจร (cycle decomposition) ให้ดู |
| 🔮 ทำนายเวทมนตร์ (10 รอบ) | ดูลักษณะข้อมูล (เกือบเรียง, กลับด้าน, ค่าซ้ำเยอะ, …) แล้วทายว่าอัลกอริทึมไหนใช้การดำเนินการน้อยที่สุด เกมจะรันทั้ง 4 ตัวจริงแล้วแสดงผลเป็นกราฟและตาราง พร้อมคำอธิบาย |
| 📖 สมุดตำรา | สรุปหลักการ ขั้นตอน Big-O (ดีสุด/เฉลี่ย/แย่สุด) หน่วยความจำ และ stability ของแต่ละอัลกอริทึม พร้อมการสาธิตแบบทีละขั้น |

## วิธีเล่น

1. เปิดเกมแล้วกด "เริ่มเล่น" จากนั้นเลือกโหมดในเมนู
2. โหมดฝึกวิชา: อ่านกฎของด่านแล้วกด "เริ่มด่าน" ทำตามคำอธิบายในแผงด้านล่าง ตอบถูกได้ +10 ตอบผิดเสียหัวใจ 1 ดวงและ −5 (มีหัวใจ 3 ดวง) ใช้คำใบ้ได้แต่ −15 ไม่ผิดเลยและไม่ใช้คำใบ้ได้ ★★★ ผ่านด่านแล้วด่านถัดไปจะปลดล็อก (ความคืบหน้าบันทึกในเบราว์เซอร์)
3. คีย์ลัด: `S` สลับ, `P` ไม่สลับ, `L` < pivot, `R` ≥ pivot, `H` ใบ้, `Esc` ยกเลิกการเลือกขวดในโหมดแข่ง
4. สัญลักษณ์บนขวด: ▲ กำลังเปรียบเทียบ, ✓ เรียงแล้ว, ★ pivot, ⬆ key, ● ขวดที่เลือกไว้

## วิธีโฮสต์บน GitHub Pages

1. สร้าง repository ใหม่บน GitHub และตั้งเป็น **Public**
2. กด **Add file → Upload files** แล้วอัปโหลด `index.html` (ใช้ไฟล์นี้ไฟล์เดียวก็พอ) จากนั้นกด Commit ไปที่ branch `main`
3. ไปที่ **Settings → Pages** ตรง Source เลือก **Deploy from a branch** แล้วเลือก branch `main` และโฟลเดอร์ `/ (root)` จากนั้นกด Save
4. รอประมาณ 1–2 นาที เกมจะเปิดได้ที่ `https://<user>.github.io/<repo>/`
   (แทน `<user>` ด้วยชื่อผู้ใช้ GitHub และ `<repo>` ด้วยชื่อ repository) ผู้ตรวจเปิดลิงก์นี้ได้โดยไม่ต้องล็อกอิน

## ทางเลือก: Netlify Drop

1. ไปที่ https://app.netlify.com/drop
2. ลากโฟลเดอร์ที่มี `index.html` มาวางในหน้านั้น
3. Netlify จะสร้างลิงก์สาธารณะให้ทันที (สมัครบัญชีเพื่อให้ลิงก์ไม่หมดอายุ)
